# Hola Maps Web

Next.js frontend application foundation.

Planned stack:
- Next.js App Router
- React
- TypeScript strict mode
- Tailwind CSS
- PWA support
- MapLibre GL JS

Responsibilities:
- Public map experience
- Place discovery
- Contributor workflows
- User profile
- Admin interfaces

The frontend must consume Hola Maps APIs and must not own GIS business logic.
